# 年度行情存储

2026-11-04 已迁移线上 Supabase 项目 vxwthnmoroyxqnloonqi。Vercel 页面通过原有 public RPC 读取它，数据库不存放在 Vercel 应用文件中。

## 表和数据口径

- `market.securities.id`：smallint 自增内部编号，证券代码仍为业务唯一键。
- `market.price_yearly`：联合主键 `(security_id, trade_year)`；`days` 是严格递增的一维当年日序数组，`close_units` 为等长正整数数组，`price_scale` 为 100（股票/指数）或 1000（旧 ETF）。价格＝整数值÷比例。不四舍五入不兼容的价格。
- `market.price_daily`：只读兼容视图，不再存储每日物理行。安全性采用 `security_invoker=true` 并沿用基础表 RLS。
- 分红原表保留，事件标识、登记日、精确现金和送转比例均未删减。

历史迁移保留全部已入库的 2021—2026 年数据，包括旧 ETF 和 ST 档案。页面搜索仅展示具有 2023 年以后行情且分红数据已采集的非 ST 沪深北 A 股。上证指数继续支持基准比较；不进入股票搜索结果。

## 读取与写入

`market_prices` / `market_history` 只读取股票编号对应、年份命中的年度块，并展开为原有日期/收盘价 JSON 格式。`market_available`、`market_ready`、`market_search` 使用同一范围；日期覆盖来自实际年度数据。页面直接调用服务端分页搜索，统一中文、拼音、代码查询和总数，避免全量缓存筛选截断分页。

`market_publish_prices` 使用事务级股票锁，验证重复日期、价格精度、范围和历史完整性后合并数组。2023 年起的新快照保留更早档案。元数据在同一事务内更新。采集任务仍被停用；后续新计划按非 ST A 股及 2023 年起构造，未在本次恢复任务。

## 验证结果

- 全部 3,119,159 条历史日行情，按证券/年份比较完整日期数组和整数价格数组，完全一致。
- 13,698 条年度记录。行情含索引 266,469,376 → 22,052,864 字节。
- 数据库整体约 312.5 MB → 68.1 MB（十进制；实际会随维护变化）。
- 公开 API 翻页遍历 2,283 只可用股票，无漏页、重复、ST 或 ETF。中文、拼音和代码均能搜到贵州茅台。
- 茅台和上证指数的 2023 年起行情各 927 个交易日，茅台同期 7 条分红事件可读。
- `tests/database_yearly.sql` 是当前存储结构的事务回滚集成测试，覆盖无损读取、跨年/闰日、旧档保留、精度、重复日期、截断快照和匿名权限。旧 `database_lean.sql` 等是旧表版本的历史测试。
- Supabase 安全与性能检查无告警。

## 迁移与回退

先创建年度表、迁移并全量比对、切换 RPC；再次比对后释放旧物理表并创建兼容视图。两个步骤各有独立迁移，未删除任何原始行情值。必要时可从兼容视图重建原每日表，然后恢复旧读写函数；预留重建每日表和索引所需空间。发布前端源码仍遵循正常 GitHub/Vercel 发布流程。
