如果当时开始定投，现在会怎样？如果从今天开始设定一个投资目标，未来又会走到哪里？拾日通过历史回测和目标记录，让这些问题变成看得见的曲线。

## 📈 历史定投回测

选择起止时间、投入金额、定投周期和股票，查看按历史行情执行计划后的模拟收益与资产变化。

- 支持搜索已采集的非 ST A 股，回测日期从 2023 年起。
- 在曲线上标记分红送转，悬停查看具体方案和按持仓计算的应收金额。
- 支持与上证指数对比，并切换日、月、年显示粒度。
- 可导出回测结果。

## 🎯 我的投资目标

设置初始资产、定期投入和目标平均收益率，推算期末目标资产与收益。之后按自己的节奏记录账户实际资产，对照目标曲线，查看真实进度和同期差额。

图表支持滚轮和触控板缩放，从完整计划放大至 7 天范围。

## 📝 使用说明

- “我的”投资计划和实际记录仅保存在当前浏览器，不跨设备同步。
- 历史回测使用已采集的不复权收盘价，并按规则计入分红送转；不模拟交易税费、整手限制等全部实际交易条件。
- 历史表现不代表未来收益，目标曲线也只是假设推算。拾日用于探索和记录，不构成投资建议。
