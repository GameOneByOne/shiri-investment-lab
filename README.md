# 拾日 · 历史定投实验室

本地单页网站：句子式定投输入、历史收益曲线、上证指数同资金流对比。

## 运行

需要 Python 3.10+ 和系统 curl，无需安装第三方依赖。

```sh
python3 server.py
```

打开 http://127.0.0.1:8765 。更换端口：`python3 server.py --port 8766`。
前端使用原生 JavaScript / CSS / SVG，不依赖 CDN、外部字体或前端构建。

## 功能

- 输入开始和结束日期，按交易日、每周指定星期、每月指定日号定投。
- 搜索 A 股、ETF 和指数，支持中文、代码、拼音；热门标的在外部搜索不可用时仍可选择。
- 收益金额、累计收益率、总资产三种曲线；按日、月末、年末采样，使用全量日线计算。
- 悬停/键盘左右键查看数据，上证指数使用相同投入日期和金额进行比较。
- 导出逐日模拟结果；响应式布局、加载和失败提示、重新计算。
- 腾讯历史行情按证券、年份、复权口径缓存在本机 `work/market.sqlite3`。
- 按需采集、限并发、失败重试、请求合并；复权历史每日刷新，避免永久使用已过期的复权值。

## 计算口径

这是价格历史模拟，不是券商成交还原。股票及 ETF 使用前复权收盘价计算虚拟份额：投入 / 当日复权价格；每日资产 = 虚拟份额 × 当日复权价格。虚拟份额不等于实际股数。不模拟手续费、税费、整手限制或真实分红现金流，不宣称是实际成交收益或精确分红再投资收益。上证指数使用原始指数点位，不能直接买入。

周/月计划遇到休市或缺少行情，顺延到下一个有该证券日线的日期；当月日号不存在则取月末，顺延超过结束日期不执行；“每天”指每个可用交易日。开始日期距首条行情超过 20 天时提示调整，以避免把上市前多年计划集中买在上市当天。未对全历史停牌及交易日历做独立校验。

收益 = 期末资产 − 累计投入；累计收益率 = 收益 / 累计投入，**不是年化收益率**。上证指数对比复用标的实际投入日期；不在买入日有缺失时使用旧价格偷偷成交。月/年曲线只选期末值，绝不累计相加收益率。

## 接口

- `GET /api/config`：最近已收盘日期、热门标的。
- `GET /api/search?q=贵州茅台`：证券搜索。
- `GET /api/history?symbol=sh600519&start=2020-01-01&end=2026-10-26`：复权日线及来源、缓存状态。

网站和 API 仅绑定 `127.0.0.1`，用于本地开发。上游地址参考 AKShare 源码，实际直接请求腾讯，无需安装 AKShare，也无需 Token。不包含商业行情分发授权或生产部署设置。

## 校验

```sh
node --test tests/engine.test.mjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

`web/engine.mjs` 为纯计算逻辑，`web/app.mjs` 为界面和图表，`server.py` 负责静态资源、搜索、采集和 SQLite 缓存。
